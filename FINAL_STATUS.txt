============================================================================

  - operational_raw populated
  - operational empty
  - Metadata initialized

Jalankan di Airflow:
  1. Go to: http://localhost:8080
  2. Find DAG: operational_incremental_loading
  3. Click: Toggle/Unpause button
  
  OR via CLI:
  airflow dags unpause operational_incremental_loading

DAG auto-runs:
  - Every 5 minutes (automatic)
  - Each run: load 1 batch (~5000 users)
  - Progress tracked in metadata
  - Auto-stops when offset >= total_users_raw

Monitor progress:
  Query: SELECT * FROM operational.pipeline_metadata;
  
  Expected progression:
  - Batch 0: offset=0
  - Batch 1: offset=5000
  - Batch 2: offset=10000
  - ...
  - Final: offset=total_users_raw (complete)
